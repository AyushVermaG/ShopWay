# ShopWay – E-commerce Website

ShopWay is a simple and user-friendly e-commerce website that offers a smooth online shopping experience. Built using HTML, CSS, and JavaScript, the platform allows users to browse products, manage their cart, and place orders with ease. It features a clean layout, responsive design, and interactive elements to enhance user engagement.

## Features

- 📦 Product listing with images, prices, and descriptions  
- 🔍 Search and filter functionality  
- 🛒 Add to cart and view cart items  
- 💳 Checkout page with order summary  
- 📱 Responsive design for mobile and desktop devices

## How to Run

1. Clone the repository or download the ZIP file.
2. Open `shopway.html` in any modern web browser.
3. Browse products, add items to the cart, and proceed to checkout.
